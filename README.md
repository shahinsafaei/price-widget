# نرخ ارز و طلا — ویجت اندروید

## ماجرا چیه؟
من (Claude) خودم نمی‌تونم روی این سیستم فایل APK کامپایل‌شده بسازم، چون به ابزارهای ساخت
اندروید (SDK گوگل) دسترسی ندارم. برای همین کل پروژه رو نوشتم و یه سیستم ساخت خودکار
(GitHub Actions) توش گذاشتم که بدون نیاز به نصب هیچ برنامه‌ای روی خودت،
APK رو برات می‌سازه. فقط چند کلیک لازمه:

## مراحل (حدود ۵ دقیقه، بدون کدنویسی)

1. یه حساب رایگان توی github.com بساز (اگه نداری).
2. یه ریپازیتوری جدید بساز (دکمه سبز "New").
3. تمام فایل‌های این پوشه رو (با ساختار پوشه‌ها) توش آپلود کن —
   از دکمه "Add file → Upload files" توی مرورگر، می‌تونی کل zip رو extract کنی و درگ‌اند‌دراپ کنی.
4. بعد از آپلود، برو به تب **Actions** بالای صفحه ریپو.
5. یه Workflow به اسم "Build APK" می‌بینی که خودش شروع به اجرا می‌کنه (چون هر push یه بار اجراش می‌کنه).
   اگه شروع نشد، دستی روی "Run workflow" بزن.
6. صبر کن (حدود ۲-۴ دقیقه) تا تیک سبز بخوره.
7. روی اون اجرا (run) کلیک کن، پایین صفحه بخش **Artifacts** یه فایل به اسم
   `app-debug-apk` هست — دانلودش کن، یه فایل zip میاد که توش `app-debug.apk` هست.
8. اون APK رو به گوشیت منتقل کن (تلگرام به خودت، ایمیل، یا کابل) و نصبش کن.
   (اندروید ممکنه بگه "منبع ناشناس" — از تنظیمات اجازه نصب رو بده، طبیعیه چون از گوگل‌پلی نیست)

## بعد از نصب
- اپ رو باز کن، لیست همه ارزها و طلاها میاد، هرکدوم رو خواستی تیک بزن.
- دکمه «ذخیره و به‌روزرسانی ویجت» رو بزن.
- دکمه «افزودن ویجت به صفحه اصلی گوشی» رو بزن تا ویجت به هوم‌اسکرین اضافه بشه.
- ویجت هر ۳۰ دقیقه خودکار آپدیت می‌شه.

## نکات مهم
- کلید API که دادی از قبل توی اپ گذاشته شده (`PrefsRepository.kt`)، نیازی به کار اضافه نیست.
- ساختار دقیق JSON که brsapi.ir برمی‌گردونه رو من نتونستم مستقیم تست کنم (سایت به کرالرها
  دسترسی نمی‌ده). اگه بعد از نصب دیدی اسم آیتم‌ها یا قیمت‌ها درست نمایش داده نمی‌شن،
  کافیه این آدرس رو با مرورگر گوشیت باز کنی:
  `https://brsapi.ir/Api/Market/gold_currency.php?key=YOUR_KEY`
  و بر اساس فیلدهای واقعی JSON، فایل `app/src/main/java/ir/pricewidget/app/data/ApiModels.kt`
  رو اصلاح کنی (اسم فیلدها رو توی `@SerializedName` عوض کن). اگه این JSON رو برام بفرستی،
  خودم اصلاحش می‌کنم.
